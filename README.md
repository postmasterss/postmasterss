# Postmasterss Website

Professional responsive travel website for **Postmasterss**.

## Included
- Featured destinations
- Sample vacation packages and pricing
- Travel experience categories
- About section
- Testimonials
- Travel request/contact form
- Responsive mobile navigation
- GitHub Pages ready

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish
Upload the files to the root of the `postmasterss` repository.

Then go to:

**Settings → Pages → Deploy from a branch → main / root → Save**

The destination photographs are loaded from Unsplash. Package names and prices are sample content and can be replaced with your actual offers.
